# Cover Letter Repository

This repository stores the LaTeX source for a cover letter.

## Files

*   `cover_letter_revised.tex`: The main LaTeX source file for the cover letter.
*   `cover_letter_jin.pdf`: The compiled PDF version of the cover letter.
*   `RCP-logos-01_1.png`: Logo image file used within the letter.
*   `LICENSE`: The license for this repository.

## Usage

To compile the `.tex` file into a PDF, you will need a LaTeX distribution installed on your system (like TeX Live, MiKTeX, or MacTeX).

Run the following command in your terminal:

```bash
pdflatex cover_letter_revised.tex
```

This will generate an updated `cover_letter_jin.pdf`.
